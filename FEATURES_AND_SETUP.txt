SETUP:
1. Start Apache and MySQL in XAMPP.
2. Import database.sql into phpMyAdmin. If you already imported the supplied campus_event_db database, do not import it again unless you want to recreate the database.
3. Open the project in NetBeans.
4. Confirm DBConnection.java uses your MySQL port, username and password.
5. Use Apache Tomcat 8.5.x (javax.servlet API; do not change imports to jakarta.servlet).
6. Clean and Build, then Run.
