# Campus Event Hub 🎓📅

An **Advanced Java Web Application** built with Java Servlets, JSP, HTML, CSS, JavaScript, and MySQL for managing campus events, student registrations, attendance, and administrative oversight.

---

## 🚀 Live Cloud Deployment (Render)
This repository includes a `Dockerfile` with embedded **Tomcat 9** and **MariaDB/MySQL**.
To deploy on **[Render](https://render.com/)**:
1. Create a new **Web Service**.
2. Connect this repository (`Campus-Event-Hub`).
3. Select **Docker** environment and click **Deploy**.
4. The database is automatically imported, and the app starts on Tomcat!
